# Omarchy Calendar

An Itsycal-style calendar and agenda for the Omarchy bar. It combines a clock,
month view, upcoming events, and quick event creation while keeping calendar
credentials outside the Omarchy shell process.

## Status

Early development. The initial release targets local calendars plus Google,
iCloud, and generic CalDAV synchronization through `khal` and `vdirsyncer`.
